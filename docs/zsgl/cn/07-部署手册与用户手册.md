# 第一部分 部署手册

## 1. 环境要求

| 项 | 要求 |
|----|------|
| 操作系统 | Windows / macOS / Linux 均可（开发构建环境为 Windows） |
| Node.js | ≥ 16（Webpack 5 / ts-loader 9 要求），建议 LTS |
| npm | 随 Node 安装 |
| 浏览器 | Chrome / Edge（Chromium 内核，支持 MV2），Firefox 可用油猴脚本形态（本项目源码含 tampermonkey 打包链路） |
| 目标站点 | `zsgl.lzlj.com` 有效账号（学习地图/课程/考试/每日积分均需登录态） |

## 2. 源码构建

```bash
# 1. 安装依赖
npm install

# 2. 生产构建（输出到 build/cxmooc-tools/src/）
npm run build

# 3. 打包 crx（可选）
npm run pack
```

构建链路说明：

- `webpack.config.js` 入口：`mooc.ts`（内容脚本主体，含 zsgl 平台逻辑）、`start.ts`、`background.ts`、`views/popup.ts`，输出至 `build/cxmooc-tools/src/`。
- `@App` 别名指向 `src/`；TypeScript 经 ts-loader 转译。
- **zsgl 独立产物**：仓库内 `build/zsgl-tools/` 为针对 zsgl 平台预打包的扩展目录（manifest 注入 `*://zsgl.lzlj.com/*`，`src/mooc.js` 为内容脚本主体）。若源码有改动，可将 `build/cxmooc-tools/src/` 下产物复制到 `build/zsgl-tools/src/` 后加载，或直接按第 3 节使用 `build/cxmooc-tools`（需按第 3.2 步修改 manifest 的 matches）。
- 油猴形态：`npm run tampermonkey`（webpack.tampermonkey.js），产物为整包 userscript。

## 3. 浏览器安装（开发者模式加载）

1. 打开 Chrome，访问 `chrome://extensions/`。
2. 右上角开启"开发者模式"。
3. 点击"加载已解压的扩展程序"，选择目录：
   - 优先：`build/zsgl-tools/`（预打包、开箱即用）；
   - 或自构建产物目录 `build/cxmooc-tools/`。
4. 若使用 `build/cxmooc-tools`，确认其 `manifest.json` 的 `content_scripts.matches` 包含 `*://zsgl.lzlj.com/*`（当前仓库 manifest 已配置）。
5. 刷新 zsgl 页面，控制台出现 `mooc start` / `当前平台：zsgl` 等日志即注入成功。

## 4. 配置项说明

配置存于 `chrome.storage.sync`（`zsgl_` 命名空间），经扩展弹出页（popup）修改：

| 配置 | 默认 | 说明 |
|------|------|------|
| 开始挂机（auto） | true | 自动执行任务的总开关；控制栏按钮可运行时切换 |
| 跳过选修（skip_elective） | false | 学习地图中跳过选修关卡 |
| 视频静音（video_mute） | true | 自动播放时静音 |
| 视频倍速（video_multiple） | 1 | 播放倍速（平台若重置会自动改回） |
| 任务切换间隔（interval） | 0.1 | 任务完成后切换下一个的延迟（分钟，±50% 随机） |
| 每日积分模式（daily_points_mode） | false | 启用每日积分悬浮面板 |
| 知识页面链接（knowledge_page_url） | 空 | 用于贡献/互动积分的知识页 URL（含 `/knowledgePage/{id}`） |
| 每日目标积分（daily_points_target） | 100 | 面板默认目标值 |
| 学习/贡献/互动积分上限 | 100/300/100 | 积分上限（与平台规则一致） |
| 考试答案导出（answer_export_enabled） | true | 考试完成后自动导出题目与答案 Markdown 文件（保存到浏览器默认下载目录） |
| 日志转存（log_persist_enabled） | true | 运行日志定期写入本地存储，页面崩溃后重开课程页自动导出日志文件；关闭后不写入任何日志 |

## 5. 升级与回滚

- **升级**：替换扩展目录内产物 → `chrome://extensions/` 点击刷新按钮 → 刷新 zsgl 页面。localStorage 信号键与配置向后兼容。
- **回滚**：还原旧版本目录文件后刷新扩展即可；跨页信号键可手动清理（见第二部分 FAQ-6）。
- **卸载**：`chrome://extensions/` 移除扩展；zsgl 域名下 localStorage 中 `zsgl_*` 键可顺带清理（不影响平台功能）。

## 6. 部署验证清单

| 步骤 | 验证点 |
|------|--------|
| 1 | 扩展加载无报错（chrome://extensions 无红色错误） |
| 2 | zsgl 页面控制台出现 `mooc start`、`当前平台：zsgl` 或对应页面标识 |
| 3 | 课程详情页出现挂机按钮（或视频自动播放） |
| 4 | 学习地图页日志出现拦截成功（queryStudymapGate） |
| 5 | 考试页解密成功（无"解密失败"错误日志） |

# 第二部分 用户手册

## 1. 快速上手

1. 按部署手册安装扩展并保持登录 zsgl 平台。
2. 直接进入课程详情页或学习地图页，扩展自动注入；默认挂机开启（`auto=true`），视频将自动播放。
3. 页面顶部控制栏可"暂停挂机 / 开始挂机"。

## 2. 功能使用指南

### 2.1 课程自动学习（courseDetail 页）

- 进入 `#/home/courseDetail/{courseId}`，扩展拦截课程数据后自动过滤未学任务并排队执行。
- **视频任务**：自动点击任务卡 → 自动播放（先静音绕过自动播放策略，再按配置恢复音量）→ 倍速/静音按配置 → 播放结束自动切下一任务。
- **SCORM 课件**：自动处理"开始"按钮并进入课件内嵌播放器播放。
- **知识点**：自动点击"立即学习"，按剩余时长等待后自动退出。
- **注意**：`document/audio/URL` 类型任务暂不支持，会自动跳过。
- 全部学完后页面自动关闭；若浏览器阻止自动关闭会弹窗提示手动关闭。

### 2.2 学习地图自动闯关（studyDetail 页）

- 进入地图页后扩展自动选择第一个未完成关卡（配置"跳过选修"则跳过选修关）并点击进入。
- 自动点击关卡内首个可执行任务（考试任务 resourceType=2 **不会**自动执行）。
- 任务在新的课程页完成后，本页自动刷新并进入下一关；考试需手动完成。

### 2.3 考试辅助（examDetail 页）

- 进入考试详情页后扩展自动解密题目数据：
  - **题库有答案**：答题过程中控制台/日志输出每题正确答案，切题时自动刷新提示；
  - **题库无答案**：扩展自动尝试破解——单选题逐选项排除（平台提交即判分），多选题先逐选项测试再组合验证，破解结果回写并提示。
- 判断题（T）按单选逻辑处理。

### 2.4 每日积分模式

1. 在扩展配置中启用"每日积分模式"，填写"知识页面链接"（从平台知识页复制地址栏 URL）。
2. 打开悬浮面板，设置学习/贡献/互动三类目标与任务延迟（秒），点击确认开始。
3. 执行顺序：**互动（知识分享）→ 贡献（知识阅读）→ 学习（刷课程）**；已达标项自动跳过。
4. 知识类任务以随机间隔自动调用平台接口刷积分，每 5 次与平台真实积分校准；连续 2 次积分无变化会自动切换任务。
5. 学习积分走课程刷取：自动打开未完成课程页挂机，完成后自动换下一个；学习积分达标后自动关闭课程页并停止。
6. 点击面板刷新可手动同步积分进度；停止按钮可随时终止（含中断进行中的请求）。

### 2.5 挂机控制

- 控制栏按钮切换 `auto` 状态，影响所有页面的自动行为；暂停后任务不再自动推进，恢复后继续。

## 3. 常见问题（FAQ）

| 编号 | 问题 | 处理建议 |
|------|------|----------|
| FAQ-1 | 页面无任何注入迹象 | 确认扩展已启用且地址为 `zsgl.lzlj.com`；检查 `chrome://extensions/` 是否有加载错误；确认当前域名版本未被改版（hash 路由须为 `/home/courseDetail/`、`/home/studyDetail`、`/home/examDetail`） |
| FAQ-2 | 视频长时间转圈不播 | 已知问题（TODO #8）。尝试刷新页面；检查网络与视频源；确认倍速设置未被平台限制 |
| FAQ-3 | 最小化后视频暂停 | 扩展含保活机制，通常 ≤5s 自动恢复；建议保持标签页可见或使用小窗 |
| FAQ-4 | 提示"被锁卡住了" | 章节被平台锁定（前置未完成），需手动完成前置内容 |
| FAQ-5 | 考试解密失败/答案为空 | 平台可能更换了 AES 密钥/IV（内置于扩展常量），需更新扩展版本；控制台会有"解密失败"日志 |
| FAQ-6 | 任务卡死不再推进 | 刷新页面重启流程；若仍卡死，可在平台域名控制台执行清理后重试：`Object.keys(localStorage).filter(k=>k.startsWith('zsgl_')).forEach(k=>localStorage.removeItem(k))` |
| FAQ-7 | 每日积分不增长 | 确认知识页链接正确且含 `/knowledgePage/{id}`；确认 sid 有效（重新登录）；积分以每 5 次调用校准为准，瞬时面板数为估算值 |
| FAQ-8 | 课程页无法自动关闭 | 浏览器仅允许关闭脚本打开的窗口；按弹窗提示手动关闭即可，不影响积分 |
| FAQ-9 | 会话过期（考试接口 -4） | 重新登录平台；扩展会自动清除缓存的 sid |
| FAQ-10 | 倍速被自动重置 | 属平台对抗行为，扩展监听 ratechange 会自动改回；若频繁失败说明平台策略升级，请更新扩展 |

## 4. 兼容性与限制

1. 仅支持 MV2 扩展环境的 Chromium 浏览器；Chrome 若逐步限制 MV2，需迁移 MV3（`web_accessible_resources`、background 等需改造）。
2. 平台前端（React/MUI、Video.js/xgplayer）升级可能导致选择器/播放按钮失效，需更新 `constants.ts` 后重新构建。
3. 自动答题依赖平台"提交即判分"行为；平台关闭该能力后无答案破解将失效（有答案题库路径不受影响）。
4. 本工具仅供学习辅助，请遵守平台使用规范；"秒过视频"等强对抗功能存在被平台记录的风险（界面已有二次确认提示）。
