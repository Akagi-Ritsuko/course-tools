## 一、存储总览

zsgl 模块**不使用关系型数据库**，数据分四类介质存储，按生命周期与共享范围分层：

| 介质 | 位置 | 共享范围 | 用途 |
|------|------|----------|------|
| chrome.storage.sync | 扩展后台，浏览器账号同步 | 同扩展全部页面/标签页 | 用户配置持久化 |
| localStorage | 页面 origin `zsgl.lzlj.com` | 同源所有标签页 | 跨页任务信号、每日积分状态 |
| Cookie `sessionInfo` | 平台写入 | 同源 | 平台会话（sid 备用来源） |
| sessionStorage | 页面 origin `zsgl.lzlj.com` | 单标签页（隔离世界各自独立） | LogRecorder 的 tabId（`zsgl_log_tab_id`，2026-09 新增） |
| 内存变量 | 内容脚本运行时 | 单页面 | 解密后题目、答题状态、临时 sid 等 |

> 说明：localStorage 仅在同一浏览器同一 profile 下可用；跨页信号依赖同源共享特性，`storage` 事件只在**其他**标签页触发，同标签页需轮询兜底——这是设计上采用"事件 + 轮询"双通道的原因。

## 二、配置存储（chrome.storage.sync）

扩展配置经 `ChromeConfigItems` 读写，键格式为 `{namespace}_{key}`；zsgl 平台由 `config.SetNamespace("zsgl")` 统一加前缀。后端存储键为 `config_storage`（JSON 序列化的整包缓存）。

### 2.1 配置键表（zsgl 命名空间）

| 键 | 类型 | 默认值 | 说明 | 读取方 |
|----|------|--------|------|--------|
| `zsgl_auto` | boolean(string) | `"true"` | 挂机总开关 | MoocLauncher、ZsglTaskControlBar、video/scorm/studyMap |
| `zsgl_skip_elective` | boolean(string) | `"false"` | 学习地图跳过选修关 | ZsglStudyMap |
| `zsgl_video_mute` | boolean(string) | `"true"` | 视频静音 | ZsglVideo/ZsglAudio |
| `zsgl_video_multiple` | number(string) | 系统配置 | 倍速（如 1/1.5/2） | ZsglVideo/ZsglAudio |
| `zsgl_interval` | number(string) | `0.1` | 任务点切换间隔（分钟，读取时±50%随机化） | MoocLauncher |
| `zsgl_daily_points_mode` | boolean(string) | `"false"` | 每日积分模式开关（当前以面板消息驱动） | 悬浮面板/ZsglDailyPoints |
| `zsgl_daily_points_target` | number(string) | `100` | 每日目标积分默认值 | ZsglDailyPoints |
| `zsgl_learning_points_limit` | number(string) | `100` | 学习积分上限 | ZsglDailyPoints |
| `zsgl_contribution_points_limit` | number(string) | `300` | 贡献积分上限 | ZsglDailyPoints |
| `zsgl_interaction_points_limit` | number(string) | `100` | 互动积分上限 | ZsglDailyPoints |
| `zsgl_knowledge_page_url` | string | `""` | 知识页链接（贡献/互动积分来源） | ZsglDailyPoints |
| `zsgl_answer_export_enabled` | boolean(string) | `"true"` | 考试完成后自动导出题目与答案 Markdown 文件 | utils/answer-exporter.ts（2026-09 新增） |
| `zsgl_log_persist_enabled` | boolean(string) | `"true"` | 运行日志落地与崩溃自动导出总开关（关闭后 record/flush/pagehide/recover 全部不写） | LogRecorder（log.ts，2026-09 新增） |

> `zsgl_log_persist_enabled` 读取须先查命名空间键 `zsgl_log_persist_enabled` 再查全局键（配置页经 `SetNamespaceConfig("zsgl",...)` 保存，实际键带 `zsgl_` 前缀；曾因只读全局键导致"开关不生效"）。

### 2.2 读写机制

- 前端（内容脚本）：`frontendGetConfig`，缓存 `window.configData || localStorage`，经 `window.postMessage({type:"cxconfig"})` 广播变更。
- 后台：`backendConfig`，`chrome.storage.sync` 持久化，`chrome.runtime` 消息同步前后台。
- 布尔值以字符串 `"true"/"false"` 存取，读取时 `toBool` 转换。

## 三、跨页信号存储（localStorage）

### 3.1 键清单

| 键模式 | 写入方 | 读取方 | 值结构 | 过期策略 |
|--------|--------|--------|--------|----------|
| `zsgl_task_{courseId\|resourceId}` | ZsglStudyMap.Start（started）/ ZsglCourse.notifyStudyMapCourseComplete（finished） | studyMap storage 监听、createStorageHandler、ChromeServerMessage 通道 | `{"status":"started\|finished","expire":number}` | expire = 写入时 + 10h（TASK_EXPIRE_MS） |
| `zsgl_daily_task_{courseId}` | ZsglDailyPoints.setTaskStarted（started）/ ZsglCourse（finished，课程页沿用前缀匹配） | ZsglDailyPoints.waitForTaskComplete（storage + 3s 轮询） | 同上 | expire = 写入时 + 30min |
| `zsgl_video_complete_{courseId}_{jobIndex}` | ZsglVideo/ZsglAudio.notifyVideoTaskComplete | ZsglDailyPoints.setupVideoCompleteListener（storage + 5s 轮询） | `{"status":"finished","courseId":"…","taskId":n,"timestamp":n}` | 读取后即 `localStorage.removeItem` |
| `zsgl_close_course_{courseId}` | ZsglDailyPoints.notifyCloseCourse | ZsglCourse.setupCloseCourseListener（storage + 3s 轮询） | `{"status":"close","courseId":"…","timestamp":n}` | 读取后即删除 |
| `zsgl_daily_points_state` | ZsglDailyPoints.load/savePointsState | 同类 | `DailyPointsState`（三类积分 current/limit/target、lastUpdate、isRunning、taskDelay） | 按天重置（lastUpdate 非 0 点当日则重新初始化） |
| `zsgl_close_course_*` 监听用键、`zsgl_daily_task_*` 完成键 | — | — | 处理后删除 | 短生命周期 |
| `zsgl_log_<world>_<tabId>`（world=main\|cs，2026-09 新增） | 各页面 LogRecorder（5s 周期落地环形缓冲） | 崩溃（pagehide 未触发）后下一个页面加载 3s 的恢复导出流程 | 环形缓冲文本（2000 行上限，含 `[mem]` 内存采样行） | 心跳停止（>30s）视为标签页已死后导出并清理 |
| `zsgl_log_<world>_hb_<tabId>` | LogRecorder 每次落地刷新 | 恢复导出的标签页存活判断 | 心跳时间戳 | 与缓冲键一同清理 |
| `zsgl_log_<world>_last` | pagehide（正常退出/跳转）转存并清空本标签页缓冲 | 恢复导出流程（文件末尾无头部附加段） | 最后一次缓冲内容 | 导出时读取 |

> `sessionInfo`（平台自身写入的登录信息，含 `sid`）由平台维护，扩展只读。

### 3.2 状态机（zsgl_task_*）

```
            studyMap.Start()
                  │
                  ▼
            ┌──────────┐   notifyStudyMapCourseComplete()
            │ started  │ ────────────────────────────────────► ┌──────────┐
            └──────────┘                                        │ finished │
                  │                                             └────┬─────┘
              10h 过期                                              │ storage 事件/轮询
                  ▼                                                 ▼
             任务失效（超时兜底）                          studyMap reload → 下一关
```

### 3.3 数据完整性设计

- **双通道检测**：`storage` 事件（跨标签页实时）+ 定时轮询（同标签页/事件丢失兜底），任一命中即处理，处理后移除键防重复消费。
- **超时兜底**：started 状态带 expire（10h/30min），等待方设超时（waitForTaskComplete 30min）避免永久阻塞。
- **原子性**：单键整体 JSON 覆盖写，无并发写冲突场景（每键单一责任写入方）。
- **心跳判死（日志键，2026-09 新增）**：恢复导出仅处理心跳超过 30s（LOG_HEARTBEAT_STALE_MS）的"已死"标签页缓冲，防止抢占存活标签页；强杀浏览器时所有标签页 pagehide 均不触发，全部缓冲同时变孤儿，一次强杀会导出 N 份文件（≠ 多次崩溃）。

| 结构 | 所在 | 字段 |

| 变量 | 说明 |

## 六、"索引"与性能建议

localStorage 键均为前缀 + 业务 ID 的 KV 形式，无索引需求；遍历场景（扫描 `zsgl_task_*`、`zsgl_video_complete_*`）使用 `localStorage.length + key(i)` 全量扫描，当前键数量小（< 20）可接受。若未来键规模增长，建议：

1. 维护一个 `zsgl_index` 集合键登记活跃任务键，避免全量扫描；
2. 轮询改为 MutationObserver/Web Worker 定时（当前为 setInterval）；
3. 为 `zsgl_video_complete_*` 增加写入时间戳 TTL 清理（现依赖消费方即时删除，异常退出时可能残留）。

## 七、数据清理策略

| 数据 | 清理时机 |
|------|----------|
| `zsgl_task_*` / `zsgl_daily_task_*` finished | 消费方（createStorageHandler / waitForTaskComplete）读取后删除 |
| `zsgl_video_complete_*` / `zsgl_close_course_*` | 消费方读取后删除 |
| `zsgl_daily_points_state` | 次日首次加载时按天重置覆盖 |
| `memorySid` / cookie sessionInfo | 考试接口 code=-4 时清除（会话过期） |
| 已知缺口 | started 状态异常中断（页面崩溃）时依赖 expire 过期，无主动清扫任务 |
