## 一、简介

本扩展为 zsgl 平台提供自动挂机辅助，主要功能：

- **课程自动学习**：自动排队未学任务，播放/完成后自动推进下一任务
- **学习地图自动闯关**：自动选关、进入任务、完成后自动下一关
- **考试辅助**：自动解密题目，展示答案或自动破解
- **每日积分模式**：自动完成互动/贡献/学习三类每日积分任务

## 二、安装与启用

1. 打开浏览器扩展管理页（Edge：`edge://extensions/`；Chrome：`chrome://extensions/`）。
2. 开启"开发人员模式"，点击"加载解压缩的扩展"，选择扩展目录。
3. 刷新 zsgl 页面，页面出现工具控制栏即注入成功。

详细构建与加载步骤见 [07-部署手册与用户手册](./07-部署手册与用户手册.md)。

## 三、快速上手

1. 登录 zsgl 平台，进入课程详情页或学习地图页，扩展自动注入并排队任务。
2. **视频任务**：请手动点击任务卡打开播放器（部分浏览器设置下视频可自动播放，见 FAQ-1），开始播放后工具自动应用静音/倍速配置；播放结束自动记录完成并切换下一任务。
3. **SCORM 课件 / 知识点任务**：自动打开并执行，无需手动操作。
4. 页面顶部控制栏可随时"暂停挂机 / 开始挂机"。

## 四、配置项速查

配置经扩展弹出页修改，存于浏览器本地（`zsgl_` 命名空间）：

| 配置 | 说明 |
|------|------|
| 自动挂机 | 所有课程页面的自动挂机总开关 |
| 跳过选修 | 学习地图中跳过选修课程 |
| 视频静音 | 播放视频时自动静音 |
| 播放倍速 | 视频播放倍数（1 为正常速度） |
| 跳转间隔 | 任务完成后切换下一个的等待时间（分钟） |
| 每日积分模式 | 启用每日积分悬浮面板 |
| 考试答案导出 | 考试完成后自动导出题目与答案 Markdown |
| 日志转存 | 日志定期写入本地，页面崩溃后重开课程页自动导出日志文件 |

## 五、常见问题（FAQ）

### FAQ-1 站点内部课程不会自动播放

**现象**：进入课程详情页后，视频不会自动开始播放。

**处理**：修改浏览器媒体自动播放权限（以 Edge 为例）：

1. 打开浏览器"设置"。
2. 进入 **隐私、搜索和服务**。
3. 找到 **媒体自动播放**（也可在地址栏直接输入 `edge://settings/content/mediaAutoplay`）。
4. 将 **"控制是否自动播放网站上的音频以及视频"** 设置为 **"允许"**。

设置完成后刷新 zsgl 课程页即可。Chrome 浏览器位置类似（设置 → 隐私和安全 → 网站设置）。

### FAQ-2 切换标签页后自动暂停

**现象**：视频播放中切换到其他标签页后，视频自动暂停。

**处理**：站点会检测标签页焦点状态。请**确保切换后的焦点页不是 zsgl 的其他页面**（如同时打开的学习地图页、其他课程页）；挂机期间建议保持视频标签页为当前焦点页。若视频已暂停，切回视频页手动点击播放即可继续。

### 其他问题

页面无注入迹象、视频转圈、考试解密失败、每日积分不增长、任务卡死等问题，见 [07-部署手册与用户手册 · FAQ](./07-部署手册与用户手册.md)。

## 五、浏览器标签页保持活动设置（推荐）

**背景**：浏览器为节省内存，默认会把后台超过一定时间（Edge 睡眠标签页 / Chrome 内存节省程序，通常 2 小时）且"不活跃"的标签页休眠或冻结。挂机中的学习页若被休眠，页面内的自动流程会暂停，课程完成通知可能延迟到你切回该标签页才处理。

**扩展已内置保活**：课程页与学习地图页启动时会自动持有 Web Lock，进入浏览器的冻结豁免名单，正常情况下无需额外设置。

**建议的双保险**：将学习相关站点加入浏览器的"始终保持活动"名单，覆盖扩展保活未生效的场景（如旧版浏览器不支持 Web Locks）：

**Edge**：

1. 地址栏输入 `edge://settings/system` 打开系统设置。
2. 找到 **节省资源和内存**（睡眠标签页）区域。
3. 在 **"从不让这些网站进入睡眠状态"** 中添加以下两个站点：
   - `zsgl.lzlj.com`
   - `lzlj.b.sanjieke.cn`

**Chrome**：

1. 地址栏输入 `chrome://settings/performance` 打开性能设置。
2. 找到 **内存节省程序**。
3. 在 **"始终保持活动状态的网站"** 中添加同样两个站点。

设置即时生效，无需重启浏览器。若无法访问 `sanjieke` 站点（未使用三方/混合课程），仅添加 `zsgl.lzlj.com` 即可。

## 六、注意事项

1. **请勿在 zsgl 页面打开开发者工具（F12）**：站点内置反调试检测，打开会导致页面被暂停或跳转空白页。
2. 页面异常崩溃后重新打开课程页，扩展会自动导出崩溃日志文件（需"日志转存"保持开启），便于排查。
3. 自动答题、倍速等强对抗功能存在被平台记录的风险，请遵守平台使用规范。
4. 平台前端升级可能导致功能失效，请及时更新扩展版本。
