## 一、引言

### 1.1 编写目的

本文档描述 course-tools 浏览器扩展中 zsgl 平台适配模块（`src/mooc/zsgl/`）的需求规格，覆盖功能需求、业务规则与非功能需求，作为设计、开发、测试与验收的依据。

### 1.2 适用范围

仅覆盖 zsgl 平台（`zsgl.lzlj.com`）相关代码，不包含扩展公共内核（`src/internal/`）的完整需求，也不包含已下线的超星（chaoxing）、智慧树（zhihuishu）、中国大学 MOOC（course163）等平台模块。

### 1.3 术语定义

| 术语 | 说明 |
|------|------|
| zsgl | 目标学习平台，域名 `zsgl.lzlj.com`，SPA 前端（React/MUI） |
| 挂机 | 扩展代替用户自动执行学习任务的过程 |
| 学习地图 | 平台的关卡式课程组织方式，每关包含若干任务 |
| 关卡（Gate） | 学习地图中的一个节点，含 gateName、status、finishTaskNum/taskNum |
| cwType | 课程任务资源类型：video/scorm/knowledge/document/audio/URL |
| sid | 平台会话 ID，位于 cookie `sessionInfo` 与 localStorage `sessionInfo` 中 |
| MoocTaskSet | 扩展内核定义的任务集接口（Init/Stop/Next/SetTaskPointer） |
| headerMap | 考试 API 请求头中的签名载体（appId/nonce/sign/timestamp/appDevicePlatform） |

## 二、功能概述

zsgl 模块以浏览器内容脚本（Content Script）形式注入 `zsgl.lzlj.com` 全站页面，依据页面 hash 路由识别三类业务页面并启动对应的自动化流程：

1. **课程详情页**（`#/home/courseDetail/{courseId}`）：拦截课程详情接口获取任务清单，对未完成任务自动构建任务队列，依次完成视频播放、SCORM 课件播放、知识点学习；任务全部完成后通过 localStorage 通知调度方并尝试关闭页面。
2. **学习地图页**（`#/home/studyDetail`）：拦截关卡接口，自动定位首个未完成关卡，点击进入任务，跨页等待任务完成信号后推进下一关。
3. **考试详情页**（`#/home/examDetail`）：拦截加密的题目详情接口并 AES 解密；若响应携带正确答案则展示提示；否则调用平台考试接口，用排除法/组合验证自动破解答案。
4. **每日积分模式**（独立任务，由悬浮面板驱动）：自动刷取学习积分（课程）、贡献积分（知识阅读 API）、互动积分（知识分享 API）三类积分，支持目标值、任务延迟配置与跨页课程调度。

## 四、业务规则需求

| 编号 | 规则 | 来源 |
|------|------|------|
| BR-01 | 课程完成判定：`courseFileArr` 中全部任务 `hasLearned === "1"`，或课程数据为空，即视为课程完成 | course.ts |
| BR-02 | 视频完成判定：`video.ended` 事件，且仅触发一次（once）；完成即写 localStorage 完成标记 | video.ts/scorm.ts |
| BR-03 | 关卡选择规则：`skip_elective` 开启时选第一个 `status !== 3` 的关卡；否则选第一个 `finishTaskNum !== taskNum` 的关卡 | studyMap.ts |
| BR-04 | 关卡内任务选择规则：取第一个 `status !== 1 && resourceType !== 2` 的任务（resourceType=2 为考试，不自动执行） | studyMap.ts |
| BR-05 | 跳关规则：关卡内未完成任务数为 0 → 标记关卡 status=3 跳下一关；未完成全为考试 → 标记 status=1 跳下一关 | studyMap.ts |
| BR-06 | 考试自动作答触发条件：解密后的题目列表中不存在任何 `isCorrect === "Y"` 的选项 | exam.ts |
| BR-07 | 题目类型校验：仅接受 S（单选）/M（多选）/T（判断）；未知类型按单选处理并告警 | exam.ts |
| BR-08 | 单选破解轮次上限：4 轮（4 个选项内必然出结果）；轮次耗尽仍未确定的记为失败 | exam-answer-strategy.ts |
| BR-09 | 每日积分任务优先级：互动积分（knowledgeShare）→ 贡献积分（knowledgeRead）→ 学习积分（course）；对应积分已满或缺少知识页链接则跳过 | dailyPoints.ts |
| BR-10 | 积分估算与校准：知识类任务每次成功调用按 +0.6 分估算；每 5 次调用拉取真实积分详情校准 | dailyPoints.ts |
| BR-11 | 任务切换触发：积分详情连续 2 次无变化（JSON 比对）时置 needSwitchTask 并切换任务 | dailyPoints.ts |
| BR-12 | 任务过期：学习地图课程任务 `zsgl_task_*` 有效期 10 小时；每日积分课程任务 `zsgl_daily_task_*` 有效期 30 分钟 | constants.ts/dailyPoints.ts |
| BR-13 | 知识点学习时长：剩余等待 = `playTime - learnedDuration + 3000ms`；剩余 ≤ 0 时立即退出 | knowledge.ts |
| BR-14 | 轮询上限：DOM 元素查找等轮询最多 10 次（MAX_ATTEMPT_COUNT）超限报错或放行 | constants.ts |
| BR-15 | 请求签名密钥环境区分：host 含 api-stg/test/stg/localhost/zsgltest/127.0.0.1/.w-stg1.zhi-niao.com/custom-stg1.zhi-niao.com 时使用 appId 作为签名密钥，否则使用正式密钥 | exam-utils.ts |
| BR-16 | 会话过期：考试 API 返回 code === "-4" 时清除内存 sid 与 cookie sessionInfo | exam-utils.ts |
| BR-17 | 配置命名空间：zsgl 平台所有配置读写均加 `zsgl_` 前缀，避免与其他平台配置冲突 | platform.ts/config.ts |

## 五、非功能需求

| 编号 | 类别 | 需求 |
|------|------|------|
| NFR-01 | 兼容性 | Chrome MV2 扩展（manifest_version 2），内容脚本在 `document_start`、all_frames 注入 |
| NFR-02 | 性能 | DOM 轮询间隔 500ms（视频查找 1000ms），暂停恢复轮询 5s，API 超时 30s；避免高频率 DOM 扫描影响页面体验 |
| NFR-03 | 可靠性 | 跨页信号采用 storage 事件 + 轮询双通道；定时器统一由 TimerManager 管理，Stop 时 clearAll，防止泄漏 |
| NFR-04 | 健壮性 | 关键外部交互（HTTP 拦截、DOM 查找、解密）需有超时/重试上限与日志；解析失败不中断主流程 |
| NFR-05 | 可观测性 | 通过 Application.App.log 分级日志（Info/Warn/Error/Debug）输出关键节点；平台存在最小化警告 |
| NFR-06 | 安全性 | 平台 AES 密钥/IV 与考试签名密钥内置在源码中（已识别为风险项，密钥轮换需同步更新） |
| NFR-07 | 可维护性 | 常量集中在 constants.ts；类型定义集中在 types.ts；平台页面选择器/文案变更只需改常量 |
| NFR-08 | 隔离性 | zsgl 配置独立命名空间；localStorage 键统一 `zsgl_` 前缀 |

## 六、约束与假设

1. 用户已登录 `zsgl.lzlj.com`，会话（sid）有效；会话过期时考试接口返回 `-4`，模块清空缓存但不自动重登录。
2. 平台前端结构（MUI 组件、`.MuiButton-label`、`span.exit`、`video#course-video_html5_api` 等选择器）在版本内保持稳定；平台升级可能导致选择器失效。
3. `document/audio/URL` 三类课程资源当前不做自动学习（需求上允许跳过，见 TODO.md）。
4. 每日积分模式依赖用户配置知识页面链接（`knowledge_page_url`），未配置时仅执行课程学习任务。
5. 考试自动破解能力依赖平台"提交即判分"的接口行为（submitQuestionAnswer → queryQuestionAnswer 可读取 isCorrect）。

## 七、验收要点

1. 课程页：未学视频按序自动播放、倍速生效、播放结束自动切换下一任务，完成后页面自动关闭。
2. 学习地图：自动进入未完成关卡 → 打开任务页 → 任务完成自动返回并进入下一关，直到全部关卡完成。
3. 考试页：题目答案正确显示；无答案场景下能自动破解并回写答案标记。
4. 每日积分：三类积分按目标刷取，达上限自动停止；积分面板数据与平台实际一致（校准后）。
